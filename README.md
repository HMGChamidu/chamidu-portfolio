# Chamidu Sandeepa — Portfolio review draft

This is a local Next.js implementation of the approved portfolio content and visual direction.

## Review the visual draft

Open `preview-standalone.html` in a browser. It is a self-contained static preview and does not need an install step.

## Run the Next.js project locally

Requirements: Node.js 20.9+.

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

For a production build:

```bash
npm run build
npm run start
```

## Before publishing

- Replace the CSS project illustrations in `app/page.tsx` with approved screenshots or short looping project videos.
- Confirm the wording and factual details of the Axcetro section. The draft intentionally avoids inventing a formal job title or dates.
- Confirm all project descriptions and repository links.
- Add a CV download only after selecting the version intended for public access.
- Set the final domain in metadata and deployment configuration after the domain is chosen.

This folder is a local review copy. It has not been pushed to GitHub or deployed to Vercel.
